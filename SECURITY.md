# Безпека

## Підтримувані версії

Виправлення безпеки виходять для останньої мінорної версії.

## Як повідомити про вразливість

Не створюйте публічний issue. Повідомте приватно одним зі способів:

- [GitHub Security Advisories](https://github.com/prro-cloud/prro-mcp/security/advisories/new);
- лист на [support@prro.cloud](mailto:support@prro.cloud) з темою «Security».

Опишіть вразливість, версію prro-mcp і кроки відтворення. Не додавайте
справжніх токенів, секретів вебхуків і персональних даних покупців.

Ми підтвердимо отримання протягом 3 робочих днів і повідомимо про
виправлення.

## Що варто знати

- `PRRO_TOKEN` — облікові дані: зберігайте його як пароль, не комітьте
  конфігурацію MCP-клієнта з токеном у репозиторій.
- Для асистента випускайте окремий токен, обмежений потрібними касами;
  відкликати його можна в кабінеті за `jti` (інструмент `whoami`).
- Сервер лише читає дані: жоден інструмент не реєструє документів у ДПС і
  не змінює налаштувань.
- Сервер не пише токен у журнал; журнал іде в stderr.
